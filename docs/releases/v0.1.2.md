# md2tex Workshop 0.1.2 beta

Version 0.1.2 adds fast hidden-label entry to the self-contained BRAT beta candidate. In a Markdown editor, **md2tex Workshop: Insert Label Metadata** inserts `<!-- [label{}] -->` and leaves the cursor inside the identifier braces. The bundled default hotkey is `Mod+Shift+L`; users may change or remove it in Obsidian Settings → Hotkeys.

## Included

- Keep the existing local Markdown-to-TeX/PDF workflow, note-owned recipes, retained diagnostics, and guarded TeX-to-Markdown round trip.
- Add an editor-only command with one insertion and explicit cursor placement; it does not compile, save, infer a label, or rewrite other Markdown.
- Add a runnable Markdown shortcut demo and a feature/limits guide that distinguish supported label placement from unsupported automatic inference.
- Preserve the three-file BRAT release shape: `main.js`, `manifest.json`, and `styles.css`.

## Verify before publication

1. From the repository root, run `npm test` and inspect the result.
2. Run `node scripts/package-plugin.cjs --format brat --out-dir tmp/brat-0.1.2` and retain its manifest and hashes.
3. Run `node scripts/public-release.cjs export --out-dir tmp/public-0.1.2`, then `node scripts/public-release.cjs verify --out-dir tmp/public-0.1.2` before adding test output or Git metadata to that fresh artifact.
4. In a disposable vault, install the exact three assets, invoke the command at a known cursor, check `<!-- [label{}] -->` and caret placement, type a valid ID, and build the [label demo](../../examples/claims/05-label-shortcut.md).
5. For hosted BRAT, attach exactly the three assets to a GitHub release tagged and named `0.1.2`, install that exact release through BRAT in a separate vault, and repeat the smoke check.

## Known boundaries

Hosted BRAT availability is not established until the matching GitHub release is actually published and installed. Automated packaged-host coverage confirms registration, hotkey metadata, inserted bytes, and cursor position; it does not replace native UI acceptance on every operating system or Obsidian version. The shortcut does not alter the bounded authoring or round-trip contracts.
