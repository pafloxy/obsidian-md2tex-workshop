# md2tex Workshop 0.1.1 beta

Version 0.1.1 is the first self-contained BRAT beta candidate. It packages the plugin as the standard `main.js`, `manifest.json`, and `styles.css` release assets while retaining the shared local compiler, PDF/log panel, linked TeX targets, deterministic diagnostics, and guarded round trips.

## Highlights

- Keep Markdown as the editable source while building local LaTeX and PDF artifacts.
- View the latest successful PDF and current compiler evidence beside the selected note.
- Copy or open generated TeX without confusing it with the independently editable linked target.
- Link one new TeX target, preview selected anchored TeX edits as a complete Markdown candidate, and apply only through a separate guarded action.
- Use an undoable editor transaction for one open note or a guarded vault write for a closed note; refuse multiple views, stale inputs, conflicts, post-transaction edits, and unconfirmed persistence.
- Restore and hash-check the bundled runtime from the three standard release files without npm installation or an additional code download.
- Run four public Markdown claim demos covering academic syntax, retained local artifacts, note-owned recipes, and guarded recovery.

## Requirements

- Desktop Obsidian; native acceptance was performed on 1.13.7, while the manifest minimum remains 1.7.2.
- Linux for the currently verified complete workflow.
- A standalone Node.js 24 executable visible to Obsidian.
- `latexmk`, a supported TeX engine, and the packages used by the selected preamble; BibTeX or Biber only when selected by the note.
- BRAT 1.1.0 or newer for release-based beta installation.

## Known limits

- The structural authoring language is bounded: images, tables, note transclusion, arbitrary Markdown extensions, arbitrary TeX restructuring, and automatic adoption of existing manuscripts are not implemented.
- Round-trip recovery is conservative and over-conflicts rather than guessing. Rebuild after an accepted Apply to establish the next checkpoint.
- Other operating systems and Obsidian versions require separate native acceptance.
- Automatic agent explanation, managed AI repair, and automatic source editing are unavailable. Ordinary compilation and round trips make no intentional provider request.
- Hosted BRAT installation is not established by local packaging or direct installation; it must be checked after this exact version is published as a GitHub release.
