# md2tex Workshop 0.1.3 beta candidate

Version 0.1.3 makes guarded TeX recovery easier to review when a collaborator has heavily rewritten the linked document, and it extends exact native recovery to canonical hyperlinks and citations. It also adds panel-level bibliography fallbacks for notes that do not declare their own bibliography recipe. This source candidate is not a hosted release until a matching `0.1.3` GitHub release is published with the three BRAT assets and installed through BRAT.

## Included

- Summarize TeX-to-Markdown changes larger than 400 added-and-removed lines or 128 KiB without running the detailed line diff or rendering either full Markdown document.
- Offer a red **Overwrite Markdown with proposed version** action for those large rewrites. It consumes the same sealed candidate and retains freshness checks, backup creation, editor or vault persistence, exact readback, and linked-state finalization; it never bypasses a refusal.
- Show ordinary review changes as git-style added and removed lines, including explicit missing-final-newline changes.
- Recover canonical generated `\href` and `\hyperref` commands into editable Markdown links. Unsafe protocols, unknown escapes, malformed labels, and ambiguous TeX remain lossless raw islands.
- Recover canonical generated `\cite` and `\printbibliography` commands into `[cite{...}]` and `[printbibliography]`. A TeX-specific nonbreaking space before `\cite` remains raw TeX when exact regeneration would otherwise change bytes.
- Add panel fallback bibliography files with explicit BibTeX or biblatex selection, a maximum of 16 entries, vault-relative path rules, regular-file checks, canonical vault containment, and note-YAML priority.
- Leave `\bibliographystyle`, `\bibliography`, `\addbibresource`, and broader existing-manuscript bibliography conventions untranslated in this release.

## Verification before publication

1. From the repository root, run `npm run test:fast` and `npm test` with Node 24, TeX/BibTeX, and Poppler available.
2. Export a fresh public artifact with `node scripts/public-release.cjs export --out-dir tmp/public-0.1.3`, then verify it before adding test output or Git metadata.
3. Build the three-file candidate with `node scripts/package-plugin.cjs --format brat --out-dir tmp/brat-0.1.3` and verify that it contains only `main.js`, `manifest.json`, and `styles.css`.
4. Run the documented quickstart through target creation, TeX editing, preview, guarded apply, rebuild, and final linked-target status.
5. In a disposable vault, load the exact three assets and smoke-test an ordinary colored patch, an oversized rewrite warning and red overwrite action, editable canonical hyperlinks and citations, and panel bibliography selection with both a valid vault-local file and a refused outside-vault symlink.
6. Publish a GitHub release tagged and named `0.1.3`, install that exact release through BRAT in a separate vault, and repeat the smoke test before claiming hosted BRAT availability.

## Known boundaries

The overwrite action is intended for a reviewed heavy TeX rewrite; it does not make arbitrary TeX import safe or automatic. Existing-manuscript bibliography commands and TeX-specific citation spacing remain TeX-owned when exact native regeneration is unavailable. Panel bibliography settings are fallbacks only; note YAML remains authoritative. The merged automated candidate has local and packaged-host coverage, while the new 0.1.3 UI requires fresh native Obsidian acceptance and a hosted BRAT installation before those delivery claims are complete.
