# md2tex Workshop 0.1.3 beta

This desktop beta supplies the three installable BRAT assets: `main.js`, `manifest.json`, and `styles.css`. The release tag, release name, and packaged manifest version are all `0.1.3`.

The package contains the complete local runtime and license notices. On first load, it restores and verifies its own runtime inside the plugin directory. It does not download additional runtime code. See [version details](https://github.com/pafloxy/obsidian-md2tex-workshop/blob/0.1.3/docs/releases/v0.1.3.md) for the guarded recovery and bibliography changes.

## Install in a disposable desktop vault

1. Install and enable BRAT from Obsidian's Community plugins. Use BRAT 1.1.0 or newer.
2. Run BRAT's **Add a beta plugin for testing** command.
3. Enter `pafloxy/obsidian-md2tex-workshop` and choose the frozen version `0.1.3` (or select this prerelease from the available versions).
4. Enable **md2tex Workshop** in Community plugins if it is not enabled automatically.
5. In Workshop settings, configure an absolute Node.js 24+ executable if Obsidian's GUI PATH does not find it. Install `latexmk`, the chosen TeX engine, and the packages required by your document recipe; BibTeX is used by the default bibliography recipe.

Start with a copy of [the quickstart note](https://github.com/pafloxy/obsidian-md2tex-workshop/blob/0.1.3/examples/quickstart/note.md). Build, inspect the PDF and log, set a disposable linked TeX target, edit TeX, preview the recovered Markdown, review it, apply, and rebuild. Preserve the generated backups and linked state. Do not use existing research notes for a first installation test.

## Verification and limits

The publication workflow exports and verifies the explicit public-file list, tests a separate copy, runs fast and full suites (including packaging, integrity, relocated three-file host, real PDF, guarded recovery, stale-input, and TeX-owned preservation tests), and checks the release assets against the reviewed SHA-256 values. It downloads and compares the uploaded draft assets before publishing. Test results are available in the **Release 0.1.3 BRAT beta** Actions run for the release commit.

The optional biblatex/Biber integration test is not enabled in this workflow. Managed AI repair remains unavailable.

**Hosted installation through BRAT has not been exercised for this exact release.** The automated Obsidian tests use a host double. Prior recorded native acceptance on Obsidian 1.13.7/Linux predates the newer 0.1.3 UI and does not validate this hosted package. Fresh native Markdown compilation, PDF viewing, and guarded editor recovery remain unverified here.

This is Linux-first and desktop-only. The worker currently requires Linux process groups; macOS and Windows worker execution are unsupported. Mobile is unsupported. The declared minimum Obsidian version is 1.7.2; that minimum is not a tested native acceptance claim. A restricted Linux environment whose `/proc` exposes process IDs from another namespace can fail the process-group guard; the guard is not bypassed.
